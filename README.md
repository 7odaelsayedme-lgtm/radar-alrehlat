# رادار الرحلات: المرحلة الأولى

موقع بيشتغل كتطبيق على الجوال. تكتب رحلتك بالكلام، وهو بيوريك:

- أفضل الرحلات مترتبة بالسعر الحقيقي، بعد ما يحسب الشنطة والمقعد.
- تقويم بأسعار كل يوم في الشهر.
- المطارات البديلة القريبة، ولو فيه منها أرخص.
- تحذير لو تاريخك واقع في موسم زحمة.
- رابط حجز مباشر من موقع شركة الطيران الرسمي، ورابط تأكيد السعر في Google Flights.

كل حاجة هنا مجانية.

## الملفات

| الفولدر | فيه إيه |
|---|---|
| `web/` | الموقع نفسه، ودي الملفات اللي بترفعها |
| `web/js/data.js` | المطارات، وشركات الطيران ورسومها، والمطارات البديلة، والمواسم. **ده الملف اللي هتعدّل فيه غالبًا** |
| `web/js/nlp.js` | المحلل اللي بيفهم طلبك المكتوب بالعربي |
| `web/js/config.js` | رابط الخادم (بتحطه بعد الخطوة 3) |
| `worker/` | الخادم الصغير على Cloudflare. بيخبّي مفتاحك وبيجيب الأسعار |
| `tests/` | اختبارات المحلل: `node tests/nlp.test.mjs` |

## الخطوات (مرة واحدة بس)

### 1) جرّب الموقع ببيانات تجريبية
الموقع بيشتغل من غير أي مفتاح، وبيكتب فوق إن الأسعار تجريبية.

- **أسهل طريقة:** ادخل [dash.cloudflare.com](https://dash.cloudflare.com)، وبعدين Workers & Pages ← Create ← Pages ← Upload assets. اسحب فولدر `web` كله وارميه هناك. هتاخد رابط زي `flight-radar.pages.dev`.
- أو على جهازك لو عندك Node.js: `npx serve web`

### 2) هات مفتاح الأسعار المجاني من Travelpayouts
1. سجّل في [travelpayouts.com](https://www.travelpayouts.com).
2. ادخل [app.travelpayouts.com](https://app.travelpayouts.com)، وبعدين **Profile** ← تبويب **API token**، وانسخ التوكن. مش محتاج موافقة، بيشتغل على طول.
3. (اختياري، للعمولة) انضم لبرنامج **Aviasales** من Programs، وانسخ رقم الشريك بتاعك (Marker / Partner ID).

> متبعتش التوكن لحد، ومتكتبوش في أي ملف. بيتحط بس بأمر `wrangler secret` اللي تحت.

### 3) ارفع الخادم على Cloudflare Workers
محتاج [Node.js](https://nodejs.org) على جهازك. افتح Terminal أو PowerShell واكتب:

```bash
cd worker
npx wrangler login              # هيفتح المتصفح، وافق
npx wrangler secret put TP_TOKEN    # الصق التوكن
npx wrangler secret put TP_MARKER   # الصق رقم الـ marker
npx wrangler deploy
```

في الآخر هيطلعلك رابط زي `https://flight-radar-api.اسمك.workers.dev`.

### 4) اربط الموقع بالخادم
1. افتح `web/js/config.js`.
2. حط الرابط اللي طلعلك:
   ```js
   export const API_BASE = "https://flight-radar-api.اسمك.workers.dev";
   ```
3. ارفع فولدر `web` تاني على Cloudflare Pages.

لو عايز محدش غيرك يستخدم الخادم: في `worker/wrangler.toml` غيّر `ALLOWED_ORIGIN` لرابط موقعك، وبعدين اعمل `npx wrangler deploy` تاني.

### 5) ثبّته على الجوال
- **آيفون:** افتح الرابط في Safari، وبعدين زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط في Chrome، وبعدين القائمة ← «تثبيت التطبيق».

## حاجات لازم تعرفها
- **الأسعار حديثة مش لحظية.** Travelpayouts بيجمع أسعار من عمليات بحث الناس في آخر ساعات أو أيام. عشان كده أكّد السعر النهائي دايمًا في موقع الشركة أو Google Flights قبل الدفع.
- **رسوم الشنطة والمقعد تقديرية.** تقدر تعدّلها في `web/js/data.js` جوه `AIRLINES`.
- **مواعيد المواسم الهجرية تقريبية.** حدّثها كل سنة في `SEASONS`.
- **الحدود المجانية:** Cloudflare Workers بيستحمل 100 ألف طلب في اليوم ببلاش. والخادم بيحفظ كل نتيجة نص ساعة عشان يوفّر الطلبات.
